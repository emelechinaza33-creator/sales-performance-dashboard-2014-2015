# 📊 Sales Performance Dashboard (2014–2015)

## Project Overview
This project is an interactive Sales Performance Dashboard developed using Microsoft Excel. It analyses sales data from 2014–2015 to provide insights into regional revenue, monthly sales trends, and sales agent performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization

## Dashboard Features
- Total Sales
- Average Sales
- Top Performing Region
- Top Performing Sales Agent
- Revenue by Region
- Monthly Sales Trend
- Sales Agents Across Regions
- Agent Performance
- Executive Summary
- Key Insights and Recommendations

## Key Findings
- Total Sales: ₦19,627.88
- Top Performing Region: Woji
- Top Performing Sales Agent: Emeka
- Average Sales: ₦456.46

## Business Recommendations
- Improve sales performance in underperforming regions.
- Monitor individual sales agent performance.
- Use monthly sales trends to support better business planning.
- Make informed decisions using sales data.
